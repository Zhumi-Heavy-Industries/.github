## 🏭 这里在做什么

猪咪重工是我放 Minecraft 工业模组和设定的地方。我喜欢研究机器之间怎么配合、生产线怎么跑起来，也喜欢给这些东西安排一点能让人记住的世界观。

一条生产线大概会这样长出来：

```mermaid
flowchart LR
  A[矿石与材料] --> B[动力]
  B --> C[机器]
  C --> D[生产线]
  D --> E[一个能玩的世界]
```

## 📐 我希望它们是这样

- 机器为什么存在，玩家应该看得懂。
- 生产线要有自己的节奏，跑起来才有成就感。
