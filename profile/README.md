## 🏭 工坊档案

猪咪重工是一个 Minecraft 工业系统与世界观实验室，关注机器之间的关系、生产线的节奏，以及一套系统如何被玩家真正理解。

我们把资源、动力、配方、机器和故事放在同一张设计图里，让每一条自动化线路都像一个小型工厂。

```mermaid
flowchart LR
  A[资源与配方] --> B[动力系统]
  B --> C[加工机器]
  C --> D[工业生产线]
  D --> E[可玩的世界观]
```

## 📐 设计原则

- **机器要有理由：** 每个模块都服务于一条可理解的生产链。
- **系统要有反馈：** 压力、效率、资源和故障都应该能被玩家观察到。
- **工业要有气质：** 数值、结构和美术共同组成一个可信的工厂世界。
